# Document Analysis & Migration Readiness Tool

## Overview

This tool analyzes PDF and DOCX documents to evaluate migration readiness for documentation platforms like Document360.

## Features

- PDF and DOCX parsing
- Structural analysis
- Readability assessment
- Migration readiness scoring
- JSON report generation

## Technologies Used

- Python
- PyMuPDF
- python-docx
- textstat
- FastAPI concepts

## Setup

pip install -r requirements.txt

## Run

python run.py

## Output

Reports are generated inside the outputs folder.
